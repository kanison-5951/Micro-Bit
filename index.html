แบบประเมินความพึงพอใจ

โครงการเสริมสร้างศักยภาพนักเรียน เพื่อเตรียมความพร้อมสู่โอลิมปิกวิชาการ สอวน. ค่าย 1

สาขาวิชา คอมพิวเตอร์ ประจำปีการศึกษา 2569 โรงเรียนสตรีภูเก็ต

คำชี้แจง: กรุณาทำเครื่องหมายหรือเลือกระดับความพึงพอใจที่ตรงกับความคิดเห็นของท่านมากที่สุด

1 ระดับความพึงพอใจต่อการเข้าร่วมโครงการ

⭐ 5 = มากที่สุด ⭐ 4 = มาก ⭐ 3 = ปานกลาง ⭐ 2 = น้อย ⭐ 1 = ควรปรับปรุง
ด้านที่ 1: ด้านเนื้อหาและการจัดกิจกรรมการอบรม
1.1 เนื้อหาในการอบรมมีความเหมาะสม
1.2 กิจกรรมในการอบรมมีความเหมาะสม
1.3 ระยะเวลาในการอบรมมีความเหมาะสม
ด้านที่ 2: ด้านวิทยากรและการถ่ายทอดความรู้
2.1 วิทยากรมีความรู้ ความเชี่ยวชาญ และตอบข้อซักถามได้ชัดเจน
2.2 วิทยากรมีเทคนิคการสอนที่น่าสนใจ และเป็นกันเอง
ด้านที่ 3: ด้านการบริหารจัดการ สิ่งอำนวยความสะดวก และภาพรวม
3.1 ความพร้อมของห้องปฏิบัติการคอมพิวเตอร์ อุปกรณ์ และสัญญาณอินเทอร์เน็ต
3.2 การดูแลต้อนรับ อาหาร/อาหารว่าง และเอกสารประกอบการอบรม
3.3 ความพึงพอใจในภาพรวมต่อการเข้าร่วมโครงการนี้

ขั้นตอนการรับ Web App URL มาใส่:

  1. เปิด Google Sheet ตามลิงก์ด้านบน
  2. ไปที่เมนู ส่วนขยาย (Extensions) → Apps Script
  3. วางโค้ดสคริปต์ลงไป (กดปุ่มคัดลอกโค้ดด้านล่าง)
  4. กด ทำการปรับใช้ (Deploy) → การปรับใช้ใหม่ (New deployment)
  5. เลือกประเภทเป็น เว็บแอป (Web App) และตั้งค่าสิทธิ์ให้เป็น ทุกคน (Anyone)
  6. คัดลอก URL ที่ได้ (ลงท้ายด้วย /exec) มาวางในช่องด้านล่างนี้
